VideoProcessingOnZynq
=====================

Project Overview
----------------
VideoProcessingOnZynq is a hardware-accelerated video processing project developed on the Xilinx Zynq platform.

The project combines FPGA hardware design and embedded software to implement real-time video processing using HDMI output and Zynq PS-PL integration.

Repository Structure
--------------------

main/
    Main project directory.

arm_fpga_04_hdmi_output/
    Hardware design files.
    Contains Vivado FPGA design, HDL sources, constraints, block designs,
    bitstream generation files, and HDMI output implementation.

pchdmi/
    Video processing application source files.

pchdmi_hw/
    Hardware platform files exported from Vivado for Vitis development.

pchdmi_system/
    Vitis software system project and embedded application sources.

webcam.py
    Python webcam/video related script.

.metadata/
    IDE metadata and workspace configuration files.

RemoteSystemsTempFiles/
    Temporary remote system files generated by the development environment.

Project Features
----------------
- FPGA-based video processing
- HDMI video output support
- Zynq Processing System (PS) + Programmable Logic (PL) integration
- Hardware/Software co-design
- Vivado + Vitis development workflow
- Real-time video processing pipeline

Development Tools
-----------------
- Xilinx Vivado
- Xilinx Vitis
- Zynq FPGA Development Board
- HDMI Display / Monitor

Build and Run Instructions
--------------------------
1. Open the hardware project in Vivado.
2. Build the hardware design.
3. Generate the bitstream.
4. Export hardware platform for Vitis.
5. Open software projects in Vitis.
6. Build the embedded application.
7. Program the FPGA and run the application.
